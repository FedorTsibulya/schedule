# Расписание

Календарь рабочего времени для свободного графика: план на неделю, факт, учёт переработок и отгулов.
Коллеги смотрят по ссылке без регистрации, редактирует только владелец.

Требования и правила расчёта — в [SPEC.md](SPEC.md).

## Как пользоваться

- **В воскресенье** откройте следующую неделю, слой «План», нажмите «✎ Редактировать».
  - Клик по шапке дня — быстрые статусы (полный день, полдня, отгул, выходной…), метки на день и заметка.
  - Протяните мышью или пальцем по ячейкам дня — выберите статус интервала или поставьте метку.
- **В следующее воскресенье** переключитесь на «Факт», отметьте, как было на самом деле
  («Как в плане» в меню дня или «Скопировать план в факт» в панели справа), и поставьте галочку
  «Факт за неделю заполнен» — только такие недели входят в баланс отгулов.
- Изменения сохраняются автоматически через пару секунд; статус виден в шапке.

## Вход владельца (один раз на каждом устройстве)

Для редактирования нужен личный токен GitHub с правом записи в этот репозиторий.

1. GitHub → аватар → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. **Token name** — например, `schedule`. **Expiration** — например, 1 год (когда истечёт, создайте новый).
3. **Repository access** → **Only select repositories** → выберите этот репозиторий.
4. **Permissions** → **Repository permissions** → **Contents** → **Read and write**.
5. **Generate token**, скопируйте его.
6. Откройте страницу расписания → «✎ Вход» в правом верхнем углу → вставьте токен.

Токен хранится только в этом браузере. Никому его не передавайте; если потеряли устройство — удалите токен на GitHub.

## Как устроено

- `index.html`, `styles.css`, `app.js` — страница; `calc.js` — расчёты; `storage.js` — загрузка и сохранение.
- Данные — `data.json` в ветке **`data`**. Сайт собирается из ветки `main`, поэтому сохранения не
  пересобирают сайт и видны коллегам сразу. Вся история изменений — в истории ветки `data`.
- `tests.html` — тесты расчётов: откройте в браузере, должно быть «Все тесты пройдены».
- Локально: `python -m http.server 8765` в папке проекта → `http://localhost:8765/`
  (изменения сохраняются в браузере). Демо-данные: `http://localhost:8765/?src=demo-data.json`.

## Перенос в другой аккаунт

Аккаунт и имя репозитория не зашиты в код — они берутся из адреса страницы.

1. Передайте репозиторий (Settings → Transfer ownership) или скопируйте его вместе с веткой `data`.
2. В новом репозитории: Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Ссылка станет `https://<новый-аккаунт>.github.io/<репозиторий>/` — отправьте её коллегам.
4. Создайте новый токен в новом аккаунте и войдите заново на своих устройствах.
