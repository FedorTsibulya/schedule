# Календарь рабочего времени — спецификация

## Назначение
Личный календарь для свободного графика: план на неделю, факт, учёт переработок и отгулов.
Редактирует только владелец, коллеги смотрят по ссылке без регистрации и видят всё.
Заголовок страницы: **«Расписание: Полина»**, под ним — время последнего обновления.

## Цикл использования
- Неделя: понедельник–воскресенье.
- В воскресенье заполняется **план** на следующую неделю.
- В следующее воскресенье заполняется **факт** за прошедшую неделю.
- Старт учёта: неделя с 12.10.2026, начальный баланс — 4 дня (32 ч).

## Статусы и цвета
| Статус                | Цвет                          |
|-----------------------|-------------------------------|
| Работа                | синий                         |
| Недоступен (точно не работаю) | красный               |
| Могу, если нужно      | травяной зелёный #55a634, прозрачность 40% — **базовый фон**, им показано всё неразмеченное время |
| Отгул                 | жёлтый, приглушённый          |
| Переработка           | малиновый — подсвечивается автоматически |

Сверх нормы: отгулы недели засчитываются в норму первыми и сверх нормы не бывают.
Работа заполняет остаток нормы (20 ч − часы отгулов недели) по порядку дней и часов;
вся работа после этого — малиновая. Сумма малинового = строка «Сверх нормы» в расшифровке
баланса. Подсвечивается и в плане (прогноз), и в факте.

## Два уровня детализации
### Уровень дня (быстрое заполнение)
| Статус дня         | Что ставится в сетку                 | В норму | Отгул, ч |
|--------------------|--------------------------------------|---------|----------|
| Полный рабочий     | работа 10:00–18:00                   | 8       | 0        |
| Полдня работы      | работа 10:00–14:00                   | 4       | 0        |
| Полдня отгул       | работа 10:00–14:00, отгул 14:00–18:00 | 8      | 4        |
| Отгул              | отгул 10:00–18:00                    | 8       | 8        |
| Выходной           | весь день «недоступен»               | 0       | 0        |

### Уровень часов
- Сетка 9:00–21:00, ячейки по 30 минут.
- Сворачиваемые блоки «ранние часы» 7:00–9:00 и «поздние часы» 21:00–24:00,
  по умолчанию свёрнуты. Если в свёрнутом блоке есть отметки — на нём виден индикатор.
- Отметка: протянуть мышью/пальцем по ячейкам → меню статуса (как создание события в Google).
- Часы дня считаются по сетке; статус дня — сводка (если часы правили вручную — «свой график, N ч»).

### Факт
- Факт по умолчанию — полная копия плана (работа, отгулы, «не работаю»; зелёный фон не переносится,
  в факте неразмеченное время серое). От этой копии отталкиваются при заполнении.
- Пока факт дня не правили, он следует за планом; после правки хранится отдельно.
- Отметка «Факт за неделю заполнен» фиксирует факт всех дней недели: правки плана задним числом
  баланс не меняют.
- «Вернуть как в плане» (меню дня) и «Вернуть факт недели к плану» (панель) сбрасывают правки факта.

## Учёт переработок
- 1 день = 8 часов. Норма: 20 ч в неделю. Производственный календарь не учитывается.
- Отгул засчитывается в норму. Недоработка баланс не уменьшает.
- Формула за неделю (W — отработано, C — часы отгулов, Cн = min(C, 20) — отгулы, засчитанные в норму):
  `изменение баланса = max(0, W + Cн − 20) − Cн`
- За неделю можно списать не больше 20 ч отгулов. Если отгулов больше нормы, показывается
  предупреждение: «Отгулов больше нормы недели: лишние N ч не спишутся с баланса —
  отметьте их как выходной». В расшифровке: «Отгулы (идут в норму): 20 ч из 24 ч».
  (отгул списывает только ту часть, которой не хватило до нормы — подтверждено).
- Баланс хранится в часах; показывается в днях с округлением вниз до 0,5 дня
  (пример: 37 ч → «4,5 дня»).
- Неделя без заполненного факта в баланс не входит; по плану показывается прогноз.

## Метки и заметки
- Свои метки с цветами («мероприятие», «встреча» …) на день или интервал;
  ранее созданные предлагаются для быстрого выбора.
- Текстовая заметка к дню.

## Виды
- **Неделя** — основной. Выбран вариант (а): переключатель «План / Факт»;
  прошедшие недели открываются на факте. Макет: `mockups/mockup.html?v=a-plan|a-fact`.
- **Месяц** — только статусы дней, метки и заметки.
- **Телефон** — 3 дня, итоги недели в отдельной панели.
- Панель итогов недели: план/факт работы, отгулы, изменение баланса, баланс, прогноз.
- Раскрывающаяся расшифровка «Из чего сложилось изменение баланса»: работа + отгулы =
  засчитано в норму − норма = сверх нормы − списано на отгулы = изменение;
  плюс список малиновых интервалов переработки по дням.
- Цвета (макет): работа #3b78e7, не работаю #e06666, могу если нужно #55a634 с прозрачностью 40%,
  отгул #f7c933, переработка #c2185b, фон факта #f9fafb.

## Платформа
- Статический сайт на GitHub Pages: `index.html` + `data.json` в том же публичном репозитории.
- Коллеги читают без входа. Владелец на каждом своём устройстве один раз вводит
  личный fine-grained токен GitHub (доступ только к этому репозиторию); сохранение —
  коммит `data.json` через GitHub API. Коллеги видят изменения примерно через минуту.
- Без сборки и зависимостей; логика расчётов покрыта тестами.
- Переносимость: владелец и имя репозитория не зашиты в код, а определяются по адресу
  страницы (`<владелец>.github.io/<репозиторий>`). Репозиторий можно передать (Transfer)
  или скопировать в другой аккаунт без правок кода.
- Экспорт не нужен.
